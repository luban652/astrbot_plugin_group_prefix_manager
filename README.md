# astrbot_plugin_group_prefix_manager

一款专为群组管理设计的 AstrBot 插件，能够自动识别群聊中的特定数字模式并将其同步为群名前缀，支持自动替换、长度截断及白名单管控。

---

## 插件简介

**astrbot_plugin_group_prefix_manager** 能够实时监控群聊消息。当成员发送独立的 5 位数字时，插件会自动将该数字设置为当前群名称的前缀。如果群名已存在旧的 5 位数字前缀，插件会执行智能替换。此外，插件内置了白名单模式，确保仅在授权群组中运行，并提供“清空”指令快速恢复原始群名。

## 功能说明

* **数字触发器**：检测群聊中独立发出的 5 位阿拉伯数字（例如：`12345`）。
* **前缀自动管理**：
    * **新增前缀**：若群名无数字前缀，直接添加。
    * **智能替换**：若群名已包含 5 位数字，则将其替换为最新发送的数字。
* **字数溢出处理**：当添加前缀导致群名超过平台字数限制时，插件会自动截断群名尾部字符，确保修改成功。
* **白名单模式**：支持按群组开启或关闭功能，防止在非目标群组误触发。
* **一键清理**：发送特定指令“清空”，即可移除群名中所有连贯的 5 位数字。

---

## 插件流程

插件的核心逻辑遵循以下内部工作流：

1.  **消息捕获**：通过 `filter.event_message_type` 监听所有群聊消息（`GROUP_MESSAGE`）。
2.  **白名单校验**：插件首先检查当前 `group_id` 是否在白名单配置中。若未开启白名单且功能未全局激活，则忽略。
3.  **正则匹配**：
    * 使用正则表达式 `^\d{5}$` 匹配独立发送的 5 位数字。
    * 匹配成功后，调用平台适配器接口获取当前群名称。
4.  **逻辑处理**：
    * **查找冲突**：检查当前群名是否已匹配 `\d{5}` 模式。
    * **构造新名称**：
        * 若存在旧前缀：替换之。
        * 若无前缀：将新数字置于群名头部。
    * **长度校验**：检测新名称长度是否超过平台阈值（通常为 20-30 字符），若超过则执行 `pop()` 操作截断末尾。
5.  **API 调用**：通过适配器（如 `aiocqhttp`）调用 `set_group_name` 接口下发修改指令。
6.  **结果反馈**：修改成功后，插件可选择性地在群内发送提示信息。

## 使用方法

### 1. 自动设置前缀
在已启用的群组中，任何成员发送纯数字消息：
* **输入**：`88888`
* **效果**：群名变为 `88888[原群名]`。如果原群名为 `12345测试群`，则变为 `88888测试群`。

### 2. 管理白名单
管理员可以通过指令控制插件的生效范围：
* **开启当前群插件功能**：`/prefix_whitelist on`
* **关闭当前群插件功能**：`/prefix_whitelist off`

### 3. 清空数字前缀
如果需要快速还原群名，移除数字标识：
* **输入**：`清空`
* **效果**：插件会识别并剔除群名中的 5 位连贯数字，恢复纯文本名称。

## 配置说明

插件通过 `_conf_schema.json` 提供以下可视化配置项：

| 配置项 | 类型 | 描述 | 默认值 |
| :--- | :--- | :--- | :--- |
| `whitelist` | list | 已启用插件功能的群组 ID 列表 | `[]` |

## 注意事项

1.  **权限要求**：机器人必须拥有该群的**管理员**权限，且群内需开放“成员修改群名”或机器人本身具备修改权限。
2.  **频率限制**：请勿频繁发送数字触发修改，避免因操作过快触发腾讯或相关平台的风控机制。
3.  **适配性**：目前主要支持 `aiocqhttp` 等支持群管理 API 的适配器。
4.  **合规性**：请确保修改的群名内容符合相关法律法规，严禁利用此功能传播违规信息。
